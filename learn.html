❓ Common Questions

How long does this take?
30+ hours total if you do all 4 phases. But you can do one phase in a weekend. It's self-paced.
Do I need to know how to code?
Basic JavaScript/Python helps, but Claude Code can write the actual code. Focus on understanding concepts, not syntax.
What if I skip Phase 1?
You'll struggle. Agents are the core of everything. Spend 6-8 hours on Phase 1 fundamentals. It's worth it.
Can I do these in a different order?
Phase 1 first, yes. After that, you can mix and match. But Prompting (Phase 2) is critical for everything else.
What projects will I build?
Real apps: automated research agent, code assistant, personal AI assistant, automated workflow bot. All deployment-ready.
Is this free?
100%. You'll need an Anthropic API key (paid usage after free tier), but the learning material is completely free.
Where do I get help?
Email mekala@gmail.com with specific questions. Each phase has links to official docs and community resources.
