❌ Troubleshooting

Q: Download too slow?
A: The app is ~200MB. Use a wired connection for faster download.
Q: "Unidentified developer" warning on Mac?
A: Right-click → Open. This is normal for unsigned apps.
⚙️ Step 3: Install the App
Follow your system's installation process.

macOS:

1. Double-click Claude Code.dmg
2. Drag Claude Code to Applications folder
3. Wait for copy to complete
4. Eject the disk image

Windows:

1. Double-click Claude-Code-Setup.exe
2. Click "Install"
3. Choose installation location (default: Program Files)
4. Wait for installation to complete
5. Check "Launch Claude Code" and click Finish

❌ Troubleshooting

Q: Installation stuck?
A: Restart your computer and try again. Make sure you have admin rights.
