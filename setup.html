❓ Common Questions

Do I need to pay for Claude?
Claude CLI and Codex require an Anthropic API key (paid usage). Free tier available. GitHub and Railway have generous free tiers for portfolio building.
Which setup should I do first?
If you're new to coding: start with Claude CLI to learn commands, then move to Codex in an editor. If you already code: start with Codex or go straight to building a portfolio.
Can I skip Integrations?
If you're just using Claude personally, you can skip it. But if you're building projects or deploying to production, Integrations explains all the essential connections.
What OS do I need?
All guides work on Mac, Linux, and Windows. We call out OS-specific steps where they matter.
How long does this actually take?
Claude CLI: 5 minutes. Codex: 5 minutes. Portfolio: 30 minutes first time. Integrations: 20 minutes. Total: under 2 hours to go from zero to deployed.
I got stuck. What now?
Each guide has a troubleshooting section for common errors. Still stuck? Email mekala@gmail.com with the error and guide number.
