❓ Common Questions

Do I need to pay for Claude?
Claude CLI and Claude Code require a paid Claude plan or an Anthropic API key (usage is billed).
Which setup should I do first?
If you're new to coding: start with Claude CLI to learn commands, then move to Claude Code in an editor. If you already code: start with Claude Code.
What OS do I need?
All guides work on Mac, Linux, and Windows. We call out OS-specific steps where they matter.
How long does this actually take?
Claude CLI: 5 minutes. Claude Code in your IDE: 5 minutes.
I got stuck. What now?
Each guide has a troubleshooting section for common errors. Still stuck? Email mekala@gmail.com with the error and guide number.
