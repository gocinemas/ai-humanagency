Setup guide

Claude Code in your IDE

Use Claude Code inside VS Code. About 5 minutes, five steps. You'll need a Claude account or an Anthropic API key.

Step 1

Install VS Code

Claude Code runs as an extension inside Visual Studio Code. If you don't have it yet, download it from code.visualstudio.com and choose your system: macOS, Windows or Linux.

Step 2

Open the Extensions panel

Open VS Code and select the Extensions icon in the left sidebar, or press Cmd+Shift+X (Mac) or Ctrl+Shift+X (Windows).

Step 3

Install Claude Code

Search for Claude Code and install the extension published by Anthropic.

Step 4

Sign in

Sign in with your Claude account, or use an API key:

  • Claude account: needs a paid Claude plan.
  • API key: create one at console.anthropic.com. Usage is billed per use.
Step 5

Try it on a small task

Open a new Python file, open the Claude Code panel and ask: "Create a hello world script in Python." Claude Code shows each change before it's saved, so you can approve or reject it.

Something not working? Check that the extension is installed and enabled, and that your sign-in is active on the account you're using.
