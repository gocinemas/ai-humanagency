The Vendor Lie

When you call OpenAI, Anthropic, or Google about enterprise pricing, they quote you API costs:

Claude API: $3 per million input tokens, $15 per million output tokens GPT-4 API: $0.03 per input token, $0.06 per output token (older pricing) Gemini API: $0.075 per million input tokens

These numbers are real. But they represent 10-15% of your actual cost.

⚠️ The Real Cost Breakdown:
  • Model API: 10-15% (what vendors quote)
  • Infrastructure: 30-45% (servers, databases, networking)
  • Data Engineering: 25-40% (data cleaning, pipelines, ETL)
  • Talent: $200k-$500k+ (hiring ML engineers, data scientists)

Real Example: Financial Services Firm

Project: AI-powered expense report categorization

Vendor Quote: "API costs ~£200/month for 10K categorizations."

Actual 6-Month Cost: £180,000

  • API costs: £1,200 (6 months)
  • Infrastructure (servers, storage): £35,000
  • Data engineering (data pipeline, quality assurance): £90,000
  • ML engineer (3 months at £120/day): £54,000

Discovery: Most expenses had messy descriptions. Required significant ETL to standardize data. Required custom validation logic. Required model fine-tuning. Vendor's "plug and play" API became 6 months of engineering.

Part 1: The Real Cost Components

1. Infrastructure Costs (30-45% of budget)

What it includes:

  • API request servers (load balancing, auto-scaling)
  • Database servers (storing model outputs, user data, audit logs)
  • Vector databases (for RAG embeddings)
  • Caching layers (Redis for request deduplication)
  • Monitoring & logging infrastructure
  • Network egress (data transfer out of cloud)
Component Monthly Cost (1M requests) Notes
API Servers £5,000-15,000 Scales with request volume
Databases £2,000-8,000 Storage + compute
Vector DB (embeddings) £1,000-5,000 Only if using RAG
Monitoring £500-2,000 DataDog, New Relic, etc.
Subtotal £8,500-30,000 Per month

2. Data Engineering (25-40% of budget)

The hidden killer: Your data is dirty. Messy descriptions, missing values, inconsistent formats. Before AI can use it, you need to clean it.

What this includes:

  • Data auditing (understanding what data you have)
  • ETL pipelines (extracting, transforming, loading data)
  • Data validation (checking quality)
  • Feature engineering (preparing data for models)
  • Data governance (compliance, access control)
Real Metric from CTO Council Survey (2026):

Enterprises report 20-30% of AI budgets go to data engineering. Most say this was severely underestimated in planning.

Why underestimated? Nobody thinks "getting data ready" is hard. Until they try.

Activity Timeline Cost (at £120/hr)

ETL pipeline build 4-8 weeks £24,000-48,000
Data validation 2-4 weeks £12,000-24,000
Ongoing maintenance 10-20 hrs/week £6,000-12,000/month

3. Talent Costs ($200k-$500k+)

You need skilled people to build this. Not junior developers. Experienced ML engineers and data scientists.

Role Annual Salary (UK) Months Needed
ML Engineer £120,000-160,000 6-12
Data Engineer £100,000-140,000 3-6
Data Scientist £90,000-130,000 2-4
Total First Year — £200k-500k+

4. Ongoing Ops & Maintenance

Once live, you pay to keep it running:

  • Monitoring for hallucinations or drift
  • Regular model updates (when Anthropic/OpenAI release new versions)
  • Incident response (production failures)
  • Data refresh & pipeline maintenance
  • Security & compliance audits

Budget: 15-25% of first-year cost, per year.

Part 2: Accurate Cost Forecasting

The Formula

Total Implementation Cost = (API Costs) + (Infrastructure) + (Data Engineering) + (Talent) + (Contingency: 20%) Typical Range: Small pilot: £50k-150k (3-4 months) Medium implementation: £200k-500k (6-9 months) Large enterprise: £1M-5M+ (12+ months)

The Cost Breakdown by Stage

Phase Duration Estimated Cost
Planning & Data Audit 4 weeks £30,000-50,000
Infrastructure Setup 6 weeks £20,000-60,000
Data Pipeline & Engineering 8 weeks £50,000-150,000
Model Integration & Testing 6 weeks £30,000-80,000
Pilot & Validation 4 weeks £20,000-40,000
Production Deployment 2 weeks £10,000-20,000
Total 26 weeks £160k-400k

Key Risks That Inflate Costs

  • Poor data quality (triples data engineering time)
  • Hallucination issues in production (adds months of testing)
  • Legacy system integration (unexpectedly complex)
  • Compliance requirements (regulatory review slows deployment)
  • Scope creep (stakeholders want "just one more feature")
Pro Tip: Budget for 6-9 months and £200k-500k. If your vendor quotes less, they're either: 1. Lying 2. Not including critical components 3. Planning to cut corners

Your Cost Forecasting Checklist

  • Calculate API costs accurately (not just per-call, but volume spikes)
  • Budget 30-45% for infrastructure
  • Budget 25-40% for data engineering (this is where overruns happen)
  • Budget for experienced talent (ML engineer: £10-15k/month)
  • Add 20% contingency (implementation always costs more)
  • Plan for ongoing ops (15-25% of first year, annually)
  • Question any quote under £100k for enterprise implementations
