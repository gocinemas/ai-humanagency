Step 1 of 5
📋 Step 1: Check what you need
Claude Code runs in your terminal. You don't need Node.js or anything else installed first.
✅ A Mac, Linux, or Windows computer
✅ A paid Claude plan (Pro, Max, Team or Enterprise) or an Anthropic Console account. The free Claude plan doesn't include Claude Code.
✅ A project folder to work in (a new empty folder is fine)

✓ Ready to Continue?

I have a paid Claude plan or a Console account
I know where my terminal is (Terminal on Mac, PowerShell on Windows)

❌ Troubleshooting

Q: Which plan do I need?
A: See claude.com/pricing. Prices and limits change, so check there before you subscribe.
⚙️ Step 2: Install Claude Code
Run one command for your system. The installer keeps Claude Code up to date by itself.

Mac, Linux or WSL:

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Prefer Homebrew on a Mac? brew install --cask claude-code also works.

❌ Troubleshooting

Q: The command fails or shows an error
A: Check the official install troubleshooting page, which matches common errors to fixes.
Q: I installed it with npm before
A: npm installs are being phased out. Run claude install to switch to the native version. Never use sudo with npm.
✅ Step 3: Check it installed
Open a new terminal window, then run:
claude --version

You should see a version number. If you do, it's installed.

✓ Installation Verified

The command shows a version number

❌ Troubleshooting

Q: command not found: claude
A: Close the terminal and open a new one so it picks up the new path. If it still fails, run claude doctor or see the troubleshooting page from step 2.
🔑 Step 4: Sign in
Go to your project folder and start Claude Code. The first time, it opens your browser so you can sign in.
cd your-project-folder
claude

Choose your Claude account (Pro, Max, Team or Enterprise) or your Anthropic Console account, and approve the sign-in in the browser. You only do this once.

To switch accounts later, type /login inside Claude Code.

❌ Troubleshooting

Q: The browser didn't open
A: Copy the link Claude Code shows in the terminal and open it yourself.
Q: It says my plan doesn't include Claude Code
A: Claude Code needs a paid plan or a Console account with credit. The free plan doesn't include it.
🎉 Step 5: Your first task
With Claude Code running in your project folder, type a request in plain English and press Enter.
> Create a hello world script in Python
[Claude Code shows the file it wants to create and asks before saving]

Claude Code asks before it changes files or runs commands, so you stay in control. Type /help to see what else it can do.

For a quick one-off question without starting a session:

claude -p "What is an LLM?"

🎊 You're done! Claude Code is ready to use.
